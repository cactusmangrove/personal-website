This is a **template static map entry**. To turn it into a real project:

1. Drop your exported map image (PNG/JPG/SVG) into `public/maps/`.
2. Copy this file in `src/content/maps/`, rename it, and update the frontmatter.
3. Write the story behind the map right here in Markdown — the data you used,
   the question you asked, what surprised you.

The text supports headings, lists, links, images, and blockquotes.

## Project question

State the question or decision the map supports. Replace all template text with
specific, verifiable details about your project.

## Data and method

Link to authoritative datasets, explain transformations, and name the tools you
used. Never present invented placeholder values as real findings.

## Findings and reflection

Summarize the spatial pattern the map reveals, its limitations, and the next
iteration you would make.
